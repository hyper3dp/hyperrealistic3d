# Credits

Many of the practitioner rules and values in `photoreal-doctrine.md`, `lighting-camera.md`, `post-compositing.md`, `animation.md` and parts of `materials.md` were adapted (rewritten, condensed and checked against this skill's existing guidance) from:

**blender-hyperrealism-skill** by Bartłomiej Kusiak — https://github.com/Bartindigital/blender-hyperrealism-skill
That project distils ~57 tutorials and talks by Blender realism artists (Blender Guru, Blender Conference talks, Kaizen, Max Hay, Gleb Alexandrov, Robin Squares, stache, Maarten Nauta, CG Cookie, CG Geek, pwnisher, Rob Tuytel/Poly Haven, Vilem Duha, PixelicaCG and others), ranked by how many independently teach each technique.

Where its values conflicted with this skill's (e.g. clamp values, subsurface scale, bevel width), this skill keeps the scale-aware value and notes the range.
